# 大鹅的奇怪暑假 · Summer

一个独立运行的 Web + AI 卡牌小游戏：七天暑假，把零碎兴趣拼成值得留下的小成果。

## 当前状态

2026-10-05：已初始化独立 Git 仓库，当前仅有设计和实施文档，尚未创建应用脚手架、安装依赖或实现游戏。没有关联远端仓库。

当前按普通浏览器网页游戏设计；钱包、链上资产、代币不属于已确定的范围。若用户后续明确要求区块链 Web3，需要另行设计。

## 文档入口

- [Maker 积分调查](docs/maker-credits.md)：已观察的额度、限制与尚未核实的能力。

## 技术方向

拟采用 TypeScript、React、Next.js；游戏界面使用 DOM/CSS/SVG，AI 通过服务端路由调用。具体依赖版本在开始实现时核验并锁定。无游戏引擎依赖，核心玩法可在 AI 未配置时完整运行。

本项目独立于 TapTap Maker。Maker 的制作积分与 Web 游戏运行时的模型调用费用分别核算。
