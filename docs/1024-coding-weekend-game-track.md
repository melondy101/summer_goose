# 1024 超能 Coding 周末｜游戏赛道要求

> 本文档是《大鹅的奇怪暑假》项目参加 WaytoAGI 1024 超能 Coding 周末（2026-10-24 ~ 25）**游戏赛道**的硬性约束清单。
> 依据来源：本地选手手册《1024 超能 Coding 周末｜选手手册》＋ 飞书官方文档《[奖池加码超400万元！1024超能Coding周末赞助揭晓](https://waytoagi.feishu.cn/wiki/Hwpuwg9ThiLD54kKYAgce5TenVe)》。

## 一、赛道定位

- **赛道名：** 🎮 游戏｜让人想再玩一局
- **标语：** 一句话变出主角，做一局让人想再玩的游戏
- **目标：** 做一个让朋友停不下来的小游戏，闯关、解谜、派对，玩法由你定；2D、3D 都行。

## 二、要做什么（核心任务）

1. 用**一句话、一张草图或一张照片**生成角色和道具，做成**能玩的小游戏**。
2. 玩法示例（可自拟）：自家猫当主角的闯关、bug 怪物解谜、派对小游戏。

## 三、用什么（工具要求）

- **工具不限**（游戏赛道与短剧、OPC 一样不限工具；用别的工具做的作品，照样参评本地前三、在地最受欢迎奖和 1024 超能大奖）。
- 角色和道具必须用 **AI 生成**。
- 再用 **AI 编程工具**把游戏做成**网页游戏**（浏览器或手机能直接玩）。

## 四、交什么（交付物）

| 交付物 | 要求 |
|---|---|
| 可玩链接 | 浏览器或手机**能直接玩**的链接 |
| 完整一局 | 从开始到重开能**完整玩一局**（开始、挑战、结算，玩完还能再来一局） |
| 操作提示 | 操作提示要**放进游戏里** |
| 主角卡 ×1 | 一句话或草图、生成的角色、游戏里的样子 |

## 五、评委看什么（评审标准）

1. **一看就会玩**
2. **能完整玩一局**
3. **主角有记忆点**
4. **玩完还想再来一局**

## 六、奖励（游戏赛道专属）

- **赛道之星：** 每条赛道 3 个，奖金 **3072 / 2048 / 1024 元**；游戏赛道前三另加**等值永久算力**。
- **OpenDev 算力：** 每人 **300 美元（约 2130 元）**，共 900 份（短剧、游戏、OPC 三赛道共享）。
  - 领取方式：10/24 10:30 后在赛事站「我的福利」**锁定游戏赛道**＋写一句话选题＋填邮箱（邮箱必须与注册 OpenDev 的一致）；**锁定后不能再换赛道**。
  - 激活入口：[OpenDev 活动加入入口](https://credits.openai-next.com/join/waytoagi1024coding)；创建 API Key 后马上保存。
  - OpenAI 兼容工具 Base URL：`https://api.openai-next.com/v1`；Claude Code / Claude 桌面版：`https://api.openai-next.com`（不带 /v1）。
  - 额度 **10/25 19:00 统一回收**。

## 八、作品提交规则

- **入口：** 赛事站（events.waytoagi.com，10/23 晚开放）。
- **必填：** 作品名称、一句话介绍、作品链接或文件、赛道（每件作品选 1 条；一人最多参加 2 条赛道，每条各交一件作品）、使用工具。
- **不用交：** 测试表、访谈记录等过程证明。
- **用了开源、模板或已有项目：** 必须在作品介绍里**注明来源和本次新增的内容**。
- **隐私：** 需要评委登录体验的账号填在「仅评委可见」一栏，别写进作品介绍。
- **展示授权：** 提交即默认同意《作品展示与使用须知》（著作权归作者；授权主办方 WaytoAGI 与赛道赞助方在活动期间及之后免费、非独家用于宣传展示）。

## 九、通用评审维度（城市评审）

| 维度 | 权重 | 看什么 |
|---|---|---|
| 完成度与可用性 | 30% | 能跑、能播、能直接用 |
| 创意 | 25% | 想法新、玩法有趣 |
| 场景价值 | 25% | 解决真实问题，有人愿意用 |
| 展示 | 20% | 3 分钟讲清做了什么、为什么做、下一步 |

- 本地前三：评委每项打 0—10 分，按权重折算取平均分。
- 全国评选：各城市及线上赛区前三进入 10/26—31 全国评审，沿用 10/25 提交的作品。
