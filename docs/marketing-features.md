# 营销功能说明（2026-10-25 新增）

本次在 M1 可玩闭环之上，按 1024 游戏赛道四个评审维度（一看就会玩 / 能完整玩一局 / 主角有记忆点 / 玩完还想再来一局）补了一批「看得见、可传播」的功能。全部为纯前端实现，无新增运行时依赖、无后端。

## 功能清单

### 1. 音效与阿满的「嘎」（主角有记忆点）
- `src/game/sfx.ts`：Web Audio 即时合成 10 种音效（选牌、合成、盖章、满袋、弃牌、末日下午、出场嘎、低落嘎、通关铃、柔和铃），零音频文件。
- 阿满的签名「嘎」在四个节点复现：开始暑假、重开新局、集齐三种展签、零展品结算。
- 右上角常驻静音开关（`sound-toggle`），偏好存 `summer.sound.v1`，默认开启；首次点按后出声（浏览器自动播放策略）。
- 触发逻辑在纯函数 `planSfx(prev, next)` 中，配 16 条单元测试。

### 2. 同一副牌挑战（玩完还想再来一局 + 传播）
- 每局自动生成 8 位种子（`GameState.runSeed`），候选牌只由 `(runSeed, runId, turn)` 决定，与玩家选择无关——同一链接所有人拿到的 14 轮候选完全一致。
- 结算页「同一副牌，换你来捡」卡片：展示种子码 + 一键复制挑战链接（`?seed=<种子>`）。
- 好友打开链接即进入同一副牌（链接种子优先于本地存档）；「再过一个暑假」会派生全新种子换一副新牌，且两位同起点的玩家重开后仍拿同一副。
- 存档 schema v1→v2 迁移链（`save.ts` 的 `MIGRATIONS`）：旧存档自动升级，补空种子表示「可续玩、不可分享」。

### 3. 展品图鉴（玩完还想再来一局）
- 结算页新增五件展品的收集进度（`展品图鉴 X/5`），未做过的灰显，重复合成计件数。
- 附「下个暑假」预告句（只差一件时点名那件），作为再开一局的钩子。

### 4. PWA「把大鹅装进口袋」（完成度 + 传播）
- `assets/manifest.webmanifest` + `assets/sw.js`：可添加到主屏幕，桌面出现大鹅图标；断网可完整玩一局。
- 图标由 `scripts/gen_icons.mjs` 从 `aman-c-simple-v1.png` 纯缩放生成（192/512/maskable/180），不重画形象。
- Service Worker 策略：页面网络优先（部署后不读旧版），带哈希的构建产物缓存优先。

### 5. 开始页主角卡与结算演出（主角有记忆点）
- 开始页顶部直接亮出阿满原图与「主角：阿满」说明（`hero-goose`）。
- 结算页展品逐个入场动画（60ms 错开，`prefers-reduced-motion` 时自动关闭）。
- 手牌/候选牌 hover 抬升、按下回弹的轻量手感。

### 6. 移动端与兜底（完成度与可用性）
- `viewport-fit=cover` + `env(safe-area-inset-*)` + `touch-action: manipulation`：刘海屏不被遮、无双击缩放延迟。
- 全局 `ErrorBoundary`：任何渲染异常落到「阿满摔了一跤」，点「拍拍土，继续」带存档刷新恢复。

## 验证

- 单元测试：`bun run test`（含音效触发、图鉴、挑战链接、种子复现、存档迁移共 35 条新增）。
- 端到端：`bunx playwright test`（新增 e2e/marketing.spec.ts：挑战链接好友复现、图鉴计数、音效开关持久化、manifest/SW/图标可达性、viewport 声明）。
- 图标再生成：`bun scripts/gen_icons.mjs`；图标校验：`bun scripts/verify_icons.mjs assets/icons/*.png`。
